# 🚀 Geostories Browser

Geostories is a smart spatial mapping and tourist safety platform built to provide real-time incident tracking, safe-zone navigation, and emergency response capabilities.

---

## ✨ Features
- 🗺️ **Interactive Spatial Mapping:** Interactive map interface powered by Leaflet.js.
- 🚨 **One-Tap Emergency SOS:** Emergency panic button for immediate incident response.
- 🛡️ **Safe Tourist Zones:** Visual geofencing indicating verified safe areas.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Mapping API:** Leaflet.js / OpenStreetMap
